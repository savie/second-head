# SECOND HEAD — Canonical Reference

Folder ini berisi baseline reference dokumentasi hasil reconcile terhadap `dev_old`.

Dokumen di folder ini membantu menemukan foundation dan hubungan Canonical saat bekerja pada SH. Dokumen tersebut **bukan pengganti source Canonical** dan tidak boleh dipromosikan menjadi Canonical secara implisit.

## Isi

- `sh_canonical_map.md` — peta ringkas foundation dan authority Canonical.
- `sh_architecture_map.md` — peta arsitektur foundation sebagai reference.
- `sh_supabase_map.md` — peta data/persistence sebagai reference.
- `sh_foundation_blueprint.md` — blueprint foundation hasil rekonstruksi.

## Aturan

Jika ada konflik, gunakan source authority yang lebih tinggi. Jangan mengubah semantik Canonical hanya berdasarkan dokumen reference di folder ini.
