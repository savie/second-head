# SECOND HEAD — Technology

Folder ini berisi dokumen yang menetapkan technology boundaries untuk pembangunan SH.

Technology tetap berada di bawah SH semantics, Canonical, dan contract yang disetujui. Dokumen di folder ini tidak menjadi authority untuk mengubah identity, ownership, authorization, privacy, governance, atau continuity semantics SH.

## Isi

Dokumen technology harus membedakan keputusan technology yang sudah ditetapkan dari pilihan implementation yang masih terbuka.
