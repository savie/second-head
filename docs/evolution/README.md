# SECOND HEAD — EVOLUTION

Working documentation area for post-foundation SH development.

## Purpose

This folder contains evolving product direction, V1.0 planning, experiments, open questions, and later development planning.

It is **NON-CANONICAL**.

Canonical architecture/semantics remain authoritative and are not changed by documents here.

## Organization

```
evolution/
├── README.md
├── V1.0/
│   ├── ROADMAP.md
│   ├── PRODUCT_DIRECTION.md
│   └── OPEN_QUESTIONS.md
└── decisions/
    └── future development decisions
```

The folder may be reorganized internally as it grows. Other documentation domains should not be moved merely to clean up this workspace.

## Rule

Resume documents record discussion history. Evolution documents turn that discussion into an evolving development plan. Architecture documents describe implementation. Canonical documents remain authority.
