# SECOND HEAD V1.0 — OPEN QUESTIONS

Status: **WORKING / NON-CANONICAL**

These are questions raised by brainstorming that should be resolved during roadmap refinement.

## Foundation

- What exactly is the verified V1.0 starting baseline?
- Which current surfaces are fully functional, partial, or cosmetic?
- Which existing bugs/blockers remain?

## UX

- What is the final navigation model?
- Which surfaces belong directly in the primary drawer?
- What should Home show?
- How much SH state should be visible without becoming a dashboard?

## Multimodal

- Multiple attachments: what limits are appropriate?
- Which file types/capabilities should be supported first?
- How should generation, upload and analysis states be presented?
- What is the exact image-generation provider/runtime path?

## Memory / Knowledge / Experience / Journey

- Which management actions are safe and useful at V1.0?
- How should provenance/source navigation work?
- How should Journey connect back to conversations and source objects?
- What belongs in global SH Search?

## Projects

- What is a Project boundary?
- How does Project scope interact with SH/account boundaries?
- Which data types can belong to a Project?

## Hands / Tools / Extensions

- What is the minimum useful tool contract?
- How should authority be represented?
- What is the difference between a built-in Tool and an Extension/Plugin?
- What execution and approval boundaries are required?

## Portability

- Which provider dependencies are acceptable?
- What belongs behind an infrastructure boundary?
- How far should multi-database support go before V1.0?
- Can the current database artifacts remain provider-neutral while deployment remains Supabase-based?

## Local / Offline / GGUF

- What offline capabilities are realistic?
- How should synchronization work?
- Where should large local model files live on Android?
- Which local inference runtime is viable without Termux?
- How should model download/update/storage be handled?

## Release

- What is the minimum V1.0 release gate?
- Which brainstorm items are V1.0, and which are explicitly post-V1.0?
