# SECOND HEAD — Architecture

Folder ini berisi architecture working reference untuk pembangunan SH dengan Flutter + Dart.

Architecture harus mengikuti Canonical, approved scope/contracts, dan Technology Boundaries. `dev_old` digunakan sebagai reference/evidence, bukan sebagai implementation baseline atau migration source.

## Isi

- `sh_flutter_dart_architecture_and_implementation_working.md` — working reference terpadu untuk reconstruction, dependency/contract mapping, gap analysis, architecture, Flutter + Dart foundation, implementation planning, dan architecture review/handoff.

Dokumen di folder ini tetap non-Canonical sampai ada keputusan eksplisit untuk mempromosikannya.
